# CyberSoul — Luxury Showcase Website

A responsive, dependency-light static website based on the CyberSoul luxury/institutional visual direction.

## Files
- `index.html` — page structure and content
- `styles.css` — complete responsive visual system
- `script.js` — navigation, scroll effects, demo incident modal and contact form

## Run locally
Open `index.html` in a browser.

For a local server (recommended):
- Python: `python -m http.server 8000`
- Then visit `http://localhost:8000`

## Deploy to GitHub Pages
1. Create/choose a GitHub repository.
2. Upload these three files to the repository root.
3. Enable GitHub Pages from repository Settings → Pages.
4. Select the main branch and `/root`.
5. Your site will be served by GitHub Pages.

## Before production
1. Replace `hello@cybersoul.example` in `script.js` with the real inquiry email.
2. Replace placeholder founder/leadership content with verified information.
3. Connect AlertEye to real authorized integrations; the dashboard shown here is explicitly a demonstration UI.
4. Add your verified privacy policy, terms and security documentation.
5. Replace any placeholder application imagery/graphics with licensed brand assets if desired.
6. Add a real form endpoint (Formspree, Netlify Forms, your own API, etc.) if you don't want to use `mailto:`.

No customer logos, performance statistics, partnerships or certifications are claimed by this template.

## Form delivery
The Private Demonstration form submits through FormSubmit to `cybersoulalerteye@gmail.com`. On the first live submission, FormSubmit may require confirmation/activation of the destination email address. The form collects name, organization, business email, region, interest and message.
